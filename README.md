# Minimalist Monochrome Developer Portfolio

A fast, lightweight, and modern portfolio built exclusively with **Vanilla HTML5, CSS3, and JavaScript**.

Zero frameworks, zero build tools, zero dependencies.

---

## ⚡ Features

- **Pure Vanilla Stack**: Standard semantic HTML5, pure CSS3, and modern ES6 JavaScript.
- **Minimalist Monochrome Theme**: `#060606` deep black background with subtle square grid geometry and border illumination.
- **Showcased Projects**: Highlights **StudyPY** and **TermChat** with direct GitHub links and feature bullets.
- **Interactive Utilities**: 1-click email copy button and back-to-top smooth scrolling.
- **Downloadable Resume**: Direct access to `cv.pdf`.

---

## 📁 Project Structure

```
├── index.html     # Main markup
├── style.css      # All styling & responsive rules
├── script.js      # Vanilla JavaScript logic (copy email, year, scroll)
├── cv.pdf         # Resume PDF
├── vercel.json    # Vercel static configuration
└── README.md
```

---

## 🚀 How to Run Locally

You don't need `npm` or any build steps. Simply open `index.html` in your browser, or use any local server:

```bash
# Using Python
python3 -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000)

---

## 🌐 Deploy to Vercel

```bash
npx vercel --prod
```
